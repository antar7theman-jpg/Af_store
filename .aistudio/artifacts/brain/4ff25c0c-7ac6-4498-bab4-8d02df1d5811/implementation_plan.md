# نظام فتح حساب Lite / Offline المجاني مع إشعار المالك الفوري

خطة عمل متكاملة لإضافة زر وشاشة مخصصة لفتح حسابات Lite / Offline مجاناً وبشكل فوري دون اشتراط موافقة المالك، مع تسجيل إشعار فوري في لوحة المالك يعرض كافة تفاصيل الحساب الجديد.

---

### مراجعة قرارات المستخدم المستخلصة
- **طريقة التسجيل**: استمارة واضحة ومباشرة لتسجيل اسم المتجر، اسم المدير، الهاتف، البريد، والرمز السري.
- **موقع الزر في شاشة الترحيب**: زر بارز وأنيق يقع مباشرة أسفل زر فتح حساب Pro التجريبي.
- **آلية إشعار المالك**: بطاقة تنبيهية وقائمة إشعارات داخلية في حساب المالك تعرض كافة بيانات الحساب المنشأ فورياً.

---

## 1. نظرة عامة وتجربة المستخدم (Overview & Core Concept)
- **الهدف**: تمكين المستخدمين الجدد من بدء استخدام النظام فوراً عبر باقة **Lite / Offline** المجانية بالكامل دون أي تعقيد أو انتظار موافقة يدوية من المالك.
- **الجمهور المستهدف**: أصحاب المتاجر والمشاريع الصغيرة الذين يحتاجون إلى نقطة بيع وإدارة مخزون ومبيعات محلية مباشرة، دون الحاجة الفورية لميزات Pro السحابية الموسعة.
- **القيمة المضافة**: انضمام سلس وسريع بدون احتكاك، مع الحفاظ على شفافية المالك ومعرفته بكافة الحسابات الجديدة عبر إشعارات لحظية مدمجة.

---

## 2. المسار التفاعلي والتصميم البصري (User Experience & Visual Design)

### مسار المستخدم الجديد (Lite Account Registration Flow)
1. **شاشة الدخول / الترحيب**:
   - أسفل بطاقة "فتح حساب Pro تجريبي لمدة 7 أيام"، يظهر زر بارز بتصميم مريح:
     - **العنوان**: "فتح حساب Lite / offline مجاني"
     - **الوصف**: "تفعيل فوري مجاناً دون الحاجة لموافقة المالك - إدارة مبيعات وفواتير أوفلاين"
     - **الأيقونة**: أيقونة متجر أو جهاز محلي مع لمسة لونية زمردية/زرقاء مريحة تعبر عن الحرية والمجانية.
2. **شاشة التسجيل المخصصة (`LiteAccountRegistrationScreen`)**:
   - حقول إدخال مدعومة بالتحقق الفوري:
     - اسم المتجر / الفرع
     - اسم المدير / المستخدم
     - رقم الهاتف للتواصل
     - البريد الإلكتروني
     - الرمز السري (PIN) للدخول السريع
   - شارة توضيحية خضراء: "حساب مجاني بالكامل - تفعيل فوري بدون انتظار موافقة".
3. **التفعيل الفوري والدخول**:
   - الضغط على "إنشاء وتفعيل الحساب فوراً".
   - إنشاء الحساب فورياً بحالة `APPROVED` مع وسم `syncMode = "lite"`.
   - تسجيل الدخول تلقائياً ونقل المستخدم مباشرة لواجهة النظام الرئيسية.

### مسار المالك (Store Owner Notification Flow)
1. **في لوحة المالك وقائمة طلبات المديرين (`PendingManagerRequestsDialog`)**:
   - إضافة قسم مخصص للإشعارات: **"حسابات Lite المنشأة حديثاً"**.
   - بطاقة إشعار تحتوي على:
     - اسم المتجر واسم المستخدم.
     - رقم الهاتف والبريد الإلكتروني وتوقيت الإنشاء.
     - شارة: **"تفعيل فوري مجاني (بدون طلب موافقة)"**.
2. **في الشريط العلوي للمالك**:
   - ظهور عداد إشعارات الحسابات الجديدة للتنبيه بوجود مستخدمين جدد فتحوا حسابات Lite.

### التعديلات البرمجية المستهدفة:
1. **`StaffAccountRepository.kt`**:
   - إضافة دالة `createLiteManagerAccount(...)`:
     - توليد الحساب فوراً بحالة `approvalStatus = StaffApprovalStatus.APPROVED`.
     - حفظ الحساب محلياً في السجل وفي Firestore.
     - كتابة إشعار تنبيه للمالك في مجموعة التنبيهات السحابية `pro_upgrade_requests` مع وسم نوعه `LITE_REGISTRATION_NOTIFICATION` ووضعه كـ `RESOLVED` / `INFORMATIONAL` حتى لا يتطلب إجراء قبول أو رفض من المالك، بل يعرض معلوماته فقط.
2. **`LiteAccountRegistrationScreen.kt`**:
   - واجهة مستخدم متكاملة وأنيقة تتبع مبادئ Material Design 3 وإرشادات التصميم.
   - دعم التراجع واستعادة الجلسة والتحقق من صحة المدخلات.
3. **`FirebaseStaffAuthComponents.kt`**:
   - دمج الزر الجديد أسفل زر Pro Trial في شاشة تسجيل الدخول الترحيبية.
   - ربط الانتقال إلى الشاشة الجديدة بسلاسة.
4. **تحديث لوحة المالك (`PendingManagerRequestsDialog` / شريط التنبيهات)**:
   - عرض بطاقة إشعار الحسابات المنشأة وتفاصيل اتصالها للمالك Deffas Antar.
